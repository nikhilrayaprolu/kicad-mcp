# LP-1106 RV1106 SBC (rev A)

LP-1106: Linux SBC on Rockchip RV1106G3 (Cortex-A7, 1 TOPS NPU, 256MB DDR3L in package). USB-C power+OTG, 10/100 Ethernet, SPI NAND boot, microSD, 2-lane MIPI CSI, debug UART, 2x10 GPIO.

65.0 × 50.0 mm, 4 layers, 137 parts, 374 vias. Generated with kicad-mcp.
